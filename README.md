# Gestion Auto-École Cameroun 🚗

Application web de gestion administrative et pédagogique pour les auto-écoles.

## 🛠 Technologies
- Java 17 / Spring Boot
- PostgreSQL
- Hibernate / Spring Data JPA

## 🚀 Installation
1. Cloner le projet : git clone ...
2. Créer la base de données PostgreSQL : db_autoecole
3. Configurer application.properties
4. Lancer : ./mvnw spring-boot:run
